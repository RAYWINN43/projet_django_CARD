## Présentation du projet

Ce projet est un projet scolaire réalisé avec le framework **Django**.

L’objectif final est de développer une plateforme web de jeu de cartes. Le
projet devra permettre à un ou plusieurs joueurs de lancer une partie, jouer des
tours, suivre l’état de la partie et afficher les scores.
